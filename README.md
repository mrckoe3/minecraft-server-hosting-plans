## MC 吃单核，CPU 怎么挑

《我的世界》服务端的主循环压在单个线程上，主频和单核性能决定 TPS 上限，核心堆到 16 核也补不回 2.9GHz 老至强的短板。1.18 之后的版本对单核的要求又抬了一截。按雨云在售机型的单核水平排下来是这样：

- **i9-14900K / 14900KF**，6.0GHz，CPU-Z 单核 880–900 分。1.20+ 大型模组整合包、几十人起步的群组服看这档。
- **Ryzen 7950X / 9950X**，5.7GHz。Linux 下单核表现和 i9 咬得很紧，高版本插件加模组混开可以考虑。
- **R9 5900X**，4.8GHz，单核 450–520 分。中高版本模组服、小型群组、基岩版轻量服的中间档。
- **Gold 6146**，4.2GHz。纯净插件服够用。
- **Platinum 8275cl**，3.9GHz。多核强、单核弱，适合低版本模组或高版本纯净插件，有免费兑换套餐。
- **E5 2666v3**，2.9GHz。单核最弱，只适合超低预算的挂机服和低版本小生存。

另一个口径值得放在一起看。一位写服务端开服教程的作者给的配置建议是"4核8G 以上，最低不要低于 4核8G"，并且点名 14900K、5900X 这类高主频 U，理由是"高版本的 Java 服很吃单核性能和内存"。雨云在售的入门面板套餐是 1核2G 和 2核4G，两边差得不小。

谁对？取决于你开什么。三五个人玩原版、区块加载范围不大，1核2G 能跑起来；十人以上、带十几个插件、或者上模组，2核4G 很快顶到天花板。卖机器的和写教程的立场本来不同，你按实际人数和模组数量在两者之间取中间值就行，不必照抄任何一边。

## 面板服还是 VPS：一句话判断

**没开过服 → 面板；要装冷门插件或自己调 JVM 参数 → VPS。**

## 服务端软件选哪个

这一步和买哪台机器同样重要，装错了核再多也卡。

- **原版（Vanilla）**：Mojang 官方服务端，跟版本最快，没有插件和 Mod，也没有内置反作弊。几个人的私服用它最省事，人一多就卡。
- **Paper**：Spigot 的高性能分支，兼容大部分 Bukkit / Spigot 插件。插件服的默认选择，性能、生态、文档都成熟。
- **Purpur**：Paper 的衍生版，可配置项更多，适合愿意读配置文档、追求极限优化的人。
- **Forge**：Mod 生态最大，大型科技、魔法整合包基本都在它上面。版本锁定严格，服务端和客户端对不上就进不去。
- **Fabric**：轻量，启动快，跟进新版本快，适合追新的轻量模组包。
- **Mohist**：把 Forge 和 Bukkit / Spigot 揉在一起，能同时跑模组和插件。它只更新到 1.20.2，想开更高版本就没得选。
- **Velocity**：代理端，把生存、小游戏、创造几个子服串成一个入口。比 BungeeCord 省内存，后端要装对应的通信插件。

一句话规则：只装插件用 Paper；只装模组看整合包选 Forge 或 Fabric；既要插件又要模组且版本不高于 1.20.2 用 Mohist；多服互联用 Velocity。

## 开服大概几步，容易卡在哪

1. **装面板**。root 权限下执行一键脚本，装完会有 `mcsm-daemon.service` 和 `mcsm-web.service` 两个服务，面板默认开在 `http://服务器IP:23333/`。
2. **端口映射**。没有独立公网 IP 的话，MCSM 的 23333、24444 和 MC 的 25565 都要在商家面板里转发出去，否则浏览器打不开面板，朋友也连不进游戏。这一步新手最容易漏。
3. **装 JDK 21**。教程用的是 Alibaba Dragonwell 21，装完 `java -version` 能看到 `21.0.3.0.3` 这类输出就对了。
4. **传服务端 jar，建实例，填启动命令**。Paper 这类直接跑 jar 的，命令形如 `java -server -Xms128M -XX:MaxRAMPercentage=95.0 -Dfile.encoding=UTF-8 -Duser.country=CN -jar paper-1.21-50.jar`。`-XX:MaxRAMPercentage=95.0` 让 JVM 最多用掉 95% 的可用内存，`-Dfile.encoding=UTF-8` 防中文乱码。
5. **首次启动会失败**，因为 `eula.txt` 里写的是 `false`，改成 `true` 再启动。
6. **改 `server.properties`**，端口、正版验证、视距都在这里调。
7. **进游戏连接**："多人游戏 → 添加服务器"，填 `公网地址:端口`。

# -Xmx4G` 那行（去掉注释、改成你要的内存），再用 `bash run.sh` 启动，不能直接 `java -jar`。

这套流程出自一份以 1.21 为最新版本写的教程，服务端文件名、面板版本、JDK 版本到现在都可能变了，当流程参考看，jar 包和版本号按当时的官方下载页取。

## 哪些人不用考虑雨云

- **玩家主要在海外**。雨云的机房以国内为主，海外节点相对少，跨洋延迟压不下来。
- **需要 99.99% SLA 的商业服**。它的定位是性价比，规格也偏固定，从 1核2G 到 4核8G，不是高端商用产品线。
- **要做内核级调优的极客**。面板套餐给不了这个，VPS 档的规格选择也不多。
- **想开 1.20.2 以上、模组和插件混跑的服务端**。问题出在 Mohist 只更新到 1.20.2，不在机器上，但结果一样：得另找方案。

市面上还有别的开服厂商，本文不展开对比，只提醒一句：同一台 CPU 在不同商家的实际可用主频、带宽质量和超售程度差别不小，看参数之外还得看退款政策。
